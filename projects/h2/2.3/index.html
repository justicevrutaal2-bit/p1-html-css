Onderzoek HTML & CSS.

Waarom noem je de eerste HTML-pagina meestal index.html?

Omdat webservers zo ingesteld staan dat ze automatisch index.html laden als je alleen de
domeinnaam intypt. De server ziet die pagina als de 'inhoudsopgave' (de index) van je map.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Het heet een Living Standard omdat er geen
vaste versies meer komen zoals vroeger (geen 'HTML6' dus). Het is een continu document dat steeds wordt geüpdatet zodra er nieuwe
features zijn. Browsers veranderen namelijk super snel, dus de HTML-regels veranderen gewoon direct mee.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Omdat CSS3 de laatste versie was die als één groot pakket werd uitgebracht. Daarna is de CSS
-werkgroep overgestapt op losse modules (zoals Flexbox, Grid en Animations).

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Verschillende browser-engines: Elke browser gebruikt een eigen 'vertaalmachine'
(Chrome gebruikt Blink, Safari gebruikt WebKit, Firefox gebruikt Gecko). Die lezen de
HTML/CSS-code net op een andere manier af.

De drie wereldwijd meest gebruikte webbrowsers (voor alle apparaten gecombineerd, inclusief desktop, mobiel en tablet) zijn:

Google Chrome (~66,4% marktaandeel)
Apple Safari (~18,3% marktaandeel)
Microsoft Edge (~6,0% marktaandeel)
